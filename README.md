# 로또

- 로또 구입 금액, 당첨번호, 보너스번호를 입력받아 해당 금액만큼 로또를 발행하고 당첨내역, 수익률을 알려준다.

## 🎯 핵심 도메인 모델

- Lotto (로또 1장)
  - [x] 6개의 번호를 가진다. 
  - [x] 생성 시점에 스스로 유효성 검사(중복, 범위) 및 정렬을 수행한다. 
  - [x] 다른 로또와 몇 개가 겹치는지(countMatch), 특정 번호를 포함하는지(contains) 계산할 수 있다.
  - [x] 정렬된 로또 번호를 가진다.

- Rank (당첨 규칙)
  - [x] 각 등수(FIRST~FIFTH, MISS)에 대한 **규칙(일치 개수, 보너스 여부)**과 **데이터(상금, 메시지)**를 캡슐화한 Enum.
  - [x] (일치 개수, 보너스 여부)를 받아서 어떤 Rank인지 알려주는 valueOf 메서드를 제공한다.
  - [x] 상금과 메시지를 알려주는 메서드를 제공하낟.

- WinningLotto (정답지 / 채점기)
  - [x] Lotto(당첨 번호 6개)와 bonusNumber(보너스 번호)를 **조합(Composition)**으로 가진다.
  - [x] 생성 시점에 당첨 번호와 보너스 번호가 겹치지 않는지 스스로 검증한다.
  - [x] userLotto 1장을 받아, Rank가 무엇인지 스스로 판별(calculateRank)한다.
     
- LottoIssuer (로또 발행기 / Factory)
  - [x] "로또 생성" 책임을 진다.
  - [x] Supplier<List<Integer>>(번호 생성 전략)에 의존하며, 외부로부터 **의존성 주입(DI)**을 받는다.
  - [x] issue(count) 메서드를 통해 Lottos 객체를 생성하여 반환한다.

- Lottos (구매한 로또 묶음 / 일급 컬렉션)
  - [ ] List<Lotto>를 감싼 일급 컬렉션이며, "로또 관리" 책임을 진다.
  - [x] LottoIssuer로부터 이미 완성된 List<Lotto>를 주입받는다.
  - [ ] WinningLotto를 받아, 통계 결과를 스스로 계산하여 반환한다. (calculateStatistics)

**🏛️ 주요 클래스 및 역할**

- Controller (흐름 제어)
  - `LottoController`: 전체 애플리케이션의 실행 흐름(로또 구매 -> 당첨 번호 입력 -> 통계 출력)을 **조율(Orchestration)**합니다.
  - `InputView와` `OutputView`를 통해 입출력을 받고, `LottoService`에 실제 처리를 **위임(Delegate)**합니다.
- Service (비즈니스 로직)
  - `LottoService`: Controller의 요청을 받아, **애플리케이션의 핵심 유스케이스(Use Case)**를 처리합니다. 
- View (입출력)
  - `InputView`: 사용자의 입력을 받는 것을 책임집니다.
    - 구입금액, 당첨번호, 보너스번호
  - `OutputView`: 사용자에게 결과를 출력하는 것을 책임집니다.
    - console 프롬프트, 발행 로또 수량, 숫자들, 당첨 통계, 수익률
- DTO (데이터 전송 객체)
  - `StatisticsDto`: Controller가 Service의 통계 결과를 OutputView로 전달하기 위해 사용하는, 출력에 필요한 데이터만 담은 객체입니다. 
  - `LottoDto`: Controller가 발행된 로또 목록을 OutputView로 전달할 때 사용합니다.
- Constants
  - `LottoConstants`: 1000 (가격), 45 (최대 숫자) 등 변하지 않는 애플리케이션 상수 값을 관리합니다. 
  - `ErrorMessage`: [ERROR]가 포함된 예외 메시지를 Enum으로 캡슐화하여 관리합니다. 
- Utils (유틸리티)
    - `Parser`: InputView가 받은 문자열("1,2,3")을 List<Integer>로 변환하는 책임을 가집니다.
     
## 기능 목록

### 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다. 

- [OutputView] "구입금액을 입력해 주세요." 문구를 출력한다.
- [InputView] 구입금액을 입력으로 받는다.

**예외사항**

- 구입금액이 1000으로 나누어 떨어지지 않는 경우 `[ERROR] 구입금액은 1,000원 단위로 입력해주세요.`
- 구입금액이 1000원 미만일 경우 `[ERROR] 구입금액은 1,000원 이상이어야 합니다.`

### 구입금액을 바탕으로 해당 수량만큼 로또 발행을 한다. 로또 번호는 오름차순으로 정렬하여 보여준다.

- [LottoService] 구입금액을 1000원으로 나눠 수량을 계산한다.
- [LottoTickets] 수량만큼 로또를 발행 및 관리한다.
- [Lotto] 로또 번호의 숫자 범위는 1~45까지이다.
- [Lotto] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- [Lotto] 로또 번호는 오름차순으로 정렬한다.
- [OutputView] "%d개를 구매했습니다." 문구를 출력한다.
- [OutputView] 로또 번호 리스트를 출력한다.
- [LottoService] 로또 번호는 오름차순으로 정렬하여 보여준다.

* 1에서 45 사이의 중복되지 않은 정수 6개 반환
  Randoms.pickUniqueNumbersInRange(1, 45, 6);
 
**예외사항**

- 로또 번호의 숫자 범위가 1~45가 아닐 경우 `[ERROR] 로또 번호가 유효하지 않은 범위에 속합니다.`
- 로또 번호가 중복된 경우 `[ERROR] 로또 번호가 중복되었습니다.`
 
### 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다. 보너스 번호를 입력 받는다.

- [OutputView] "당첨 번호를 입력해 주세요." 문구를 출력한다.
- [InputView] 쉼표를 사용한 숫자 6개를 입력한다.
- [OutputView] "보너스 번호를 입력해 주세요." 문구를 출력한다.
- [InputView] 숫자 하나를 입력한다.

**예외사항**

- 숫자, 쉼표외의 문자열 입력이 들어온 경우 `[ERROR] 쉼표를 사용하여 숫자 6개를 입력해주세요.`
- null or 빈 문자열일 경우 `[ERROR] 입력이 비어있습니다, 다시 입력해주세요.`
- 당첨번호의 갯수가 6개가 아닌 경우 `[ERROR] 쉼표를 사용하여 숫자 6개를 입력해주세요.`
- 보너스 번호의 갯수가 1개가 아닌 경우 `[ERROR] 보너스 번호는 하나만 입력해주세요.`
- 보너스 번호가 숫자가 아닌 경우 `[ERROR] 올바른 숫자를 입력해주세요.`
- 당첨번호와 보너스번호가 중복되는 경우 `[ERROR] 당첨번호와 중복됩니다, 다시 입력해주세요.`
 
### 당첨 내역을 출력한다. 

- [OutputView] 당첨 통계를 출력한다.
- [Rank] 5,4,3,2,1등마다 각각의 메세지, 갯수를 가진다.
- [WinningLotto] 당첨번호, 보너스번호와 비교해서 일치 갯수를 계산한다.
- [WinningLotto] 보너스번호를 추가로 가진다(`Lotto` 포함 관계)
 

### 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

- [OutputView] "총 수익률은 *.0%입니다." 문구를 출력한다.
- [LottoService] 총 당첨금액 / 구입금액 * 100 -> 소수점 둘째 자리에서 반올림한다.
    
### 예외 처리 정책

* 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다.
* "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
* `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

### 입출력 요구 사항

#### 입력

* 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.




    14000


* 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.




    1,2,3,4,5,6


* 보너스 번호를 입력 받는다.




    7


#### 출력

* 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.




    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43] 
    [3, 5, 11, 16, 32, 38] 
    [7, 11, 16, 35, 36, 44] 
    [1, 8, 11, 31, 41, 42] 
    [13, 14, 16, 38, 42, 45] 
    [7, 11, 30, 40, 42, 43] 
    [2, 13, 22, 32, 38, 45] 
    [1, 3, 5, 14, 22, 45]


* 당첨 내역을 출력한다.




    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개


* 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)




    총 수익률은 62.5%입니다.


* 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.




    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
